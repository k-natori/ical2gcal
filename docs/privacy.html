プライバシーポリシー

iCal2gCal ／ 制定日: 2026年10月17日

iCal2gCal（以下「本ツール」）は、macOS の「カレンダー」の予定を利用者本人の Google カレンダーへ複製する個人用のツールです。 本ポリシーでは、本ツールが扱う情報とその取り扱いについて説明します。

1. 取得する情報

  • Mac のカレンダーの予定：利用者が設定で指定したカレンダーの予定のタイトル、開始・終了日時、終日かどうか、場所、メモ、URL。macOS の EventKit を通じて、利用者の Mac 上で読み取ります。
  • Google カレンダーの情報：Google Calendar API を通じて、カレンダーの一覧（同期先の確認用）と、同期先カレンダーのうち本ツールが作成した予定の ID と日時。
  • 認証情報：Google の OAuth クライアント ID、クライアントシークレット、リフレッシュトークン。

2. 利用目的

取得した情報は、Mac の予定を利用者本人の Google アカウント内の専用カレンダーに作成・更新・削除するためだけに使います。 広告、分析、プロファイリング、機械学習モデルの学習には使いません。

3. 保存場所

  • 認証情報は、利用者の Mac のキーチェーンに保存します。
  • 同期の状態（予定の識別子、Google 側の予定 ID、変更検知用のハッシュ値、日時）は、利用者の Mac 上の ~/Library/Application Support/CalSync/state.sqlite に保存します。予定のタイトルやメモの本文はここには保存しません。
  • 動作ログは ~/Library/Logs/CalSync/ に保存します。メモの本文などは記録しません。

4. 第三者への提供

本ツールは、利用者の Mac と Google の API の間で直接通信します。開発者が運営するサーバーはありません。 取得した情報を開発者や第三者に送信・提供・販売することはありません。

5. Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に従います。

6. データの削除とアクセスの取り消し

  • calsync reset を実行すると、同期先カレンダーから本ツールが作成した予定と、Mac 上の同期状態を削除します。
  • キーチェーンアクセスで com.calsync.cli の項目を削除すると、保存した認証情報が消えます。
  • 本ツールの Google アカウントへのアクセスは、Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

7. 改定

本ポリシーを改定する場合は、このページを更新し、制定日・改定日を記載します。
